Family NFL Picks v0.9.1 — Future-game lock fix

NO PICKS, POINTS, MARGINS, HISTORY, STANDINGS, PINS, GAMES, OR OVERRIDES ARE RESET.

1) SUPABASE
Open Supabase -> SQL Editor -> New query.
Run V091_RUN_ONCE_IN_SUPABASE_LOCK_FIX.sql once.

The SQL can remove ONLY an invalid/stale submission marker for a player who is not actually complete. That is intentional: it is what prevents a future game from being falsely locked. Their saved picks remain untouched.

2) GITHUB
Upload the website files in this folder to GitHub, replacing v0.9.0.

New rule enforced by v0.9.1:
- Future game is locked if that game's kickoff has happened, OR
- all 4 players are genuinely submitted AND each currently has every game picked.
- If Limar is 1/14, everyone-submitted lock is FALSE.

Everything else from v0.9.0 is unchanged, including confetti, 4-second Congrats screen, raw cumulative scoring, live standings, checkmarks, NFL refresh behavior, theme, and four-player setup.
